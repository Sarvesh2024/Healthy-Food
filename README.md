# Employee Management System

A modern, fully-featured Employee Management System built with HTML, CSS, and JavaScript. This single-page application allows you to manage employee records with an intuitive user interface and persistent local storage.

## 🌟 Features

### Core Functionality
- **Add Employees**: Create new employee records with comprehensive information
- **View Employees**: Display all employees in an organized table format
- **Edit Employees**: Modify existing employee information
- **Delete Employees**: Remove employees from the system
- **View Details**: Click on "View" button to see full employee details in a modal window

### Search & Filter
- **Search by Name**: Quickly find employees by their full name
- **Search by Email**: Look up employees using their email address
- **Filter by Department**: View employees by specific departments
- **Reset Filters**: Clear all filters to see the complete employee list

### Data Management
- **CSV Export**: Download employee data as a CSV file for use in spreadsheets
- **Local Storage**: All data is automatically saved to your browser's local storage
- **No Backend Required**: Operates completely in the browser

### Statistics
- **Total Employees**: Real-time count of all employees
- **Active Departments**: Number of unique departments represented
- **Average Salary**: Calculated average salary across all employees

### User Interface
- **Dark Mode**: Toggle between light and dark themes for comfortable viewing
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern Styling**: Clean, professional interface with smooth animations
- **Modal Details**: View complete employee information in a popup dialog

## 📋 Employee Information Stored

Each employee record includes:
- **Full Name**: Employee's complete name
- **Email**: Corporate email address
- **Phone**: Contact phone number (optional)
- **Department**: Department assignment (Engineering, Marketing, Sales, HR, Finance, Operations, Product)
- **Position**: Job title or role
- **Salary**: Annual salary amount
- **Start Date**: Employment start date
- **Years of Service**: Automatically calculated

## 🚀 Getting Started

### Installation
1. Download the `index.html` file
2. Place it in a folder on your computer
3. Open it in any modern web browser (Chrome, Firefox, Safari, Edge, etc.)

### Usage
1. **Adding an Employee**:
   - Fill in all required fields in the "Add New Employee" form
   - Click the "Add Employee" button
   - The employee will appear in the employee list below

2. **Searching for Employees**:
   - Type in the search box to find by name or email
   - Results update in real-time

3. **Filtering by Department**:
   - Select a department from the filter dropdown
   - View only employees in that department
   - Click "Reset Filters" to see all employees again

4. **Viewing Employee Details**:
   - Click the "View" button next to an employee
   - A modal window will display all their information

5. **Editing an Employee**:
   - Click the "Edit" button next to an employee
   - The form will populate with their data
   - Modify the information as needed
   - Click "Add Employee" to save the updated record

6. **Deleting an Employee**:
   - Click the "Delete" button next to an employee
   - Confirm the deletion when prompted
   - The employee will be removed immediately

7. **Exporting Data**:
   - Click the "Export to CSV" button in the search/filter panel
   - A CSV file will be downloaded with all employee data
   - Open in Excel, Google Sheets, or any spreadsheet application

8. **Dark Mode**:
   - Click the "Dark Mode" button in the header
   - The interface will switch to a dark theme
   - Your preference is saved automatically

- Use the "Export to CSV" feature to backup your employee data
- Save the CSV file to your computer for safekeeping

## 🐛 Troubleshooting

### Data Not Saving
- Check if browser allows local storage
- Try clearing browser cache and reloading
- Use a different browser

### Filter Not Working
- Ensure department names match exactly
- Check spelling in search terms
- Click "Reset Filters" and try again

### Export Not Working
- Check if browser blocks downloads
- Try a different browser
- Ensure you have at least one employee

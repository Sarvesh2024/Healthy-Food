## First Time Setup

### Step 1: Open the Application
1. Download `index.html` 
2. Double-click the file to open in your browser
3. You should see the Employee Management System dashboard

### Step 2: Familiarize Yourself with the Interface
- **Header**: Application title and dark mode toggle
- **Statistics Panel**: Shows key metrics at the top
- **Left Panel**: Form for adding new employees
- **Right Panel**: Search, filter, and export options
- **Bottom Panel**: Employee list table

## Adding Your First Employee

### Required Information
1. **Full Name** - Employee's complete name (required)
2. **Email** - Corporate email address (required)
3. **Department** - Choose from predefined list (required)
4. **Position** - Job title (required)
5. **Salary** - Annual salary in numbers only (required)
6. **Start Date** - Employment start date (required)

### Optional Information
- **Phone Number** - Contact phone number (optional)

### Steps to Add
1. Fill in all required fields marked with *
2. Enter optional information if available
3. Click "Add Employee" button
4. You'll see a success message
5. New employee appears in the table below

**Example:**
```
Name: Sarah Johnson
Email: sarah.johnson@company.com
Department: Engineering
Position: Senior Software Engineer
Salary: 120000
Phone: (555) 123-4567
Start Date: 2023-01-15
```

## Common Tasks

### ✅ View Employee Details
1. Click the **View** button next to an employee's name
2. A popup window shows all their information
3. Click the X or outside to close

### ✏️ Edit an Employee
1. Click the **Edit** button next to their name
2. Form fields populate with their current data
3. Change any information you need to update
4. Click "Add Employee" to save changes
5. The updated employee appears in the list

### 🗑️ Delete an Employee
1. Click the **Delete** button next to their name
2. Confirm you want to delete (click OK in the popup)
3. Employee is immediately removed
4. Statistics update automatically

### 🔍 Search for Employees
1. Go to the **Search by Name or Email** field
2. Start typing a name or email
3. Table filters in real-time as you type
4. Results update instantly

### 📊 Filter by Department
1. Use the **Filter by Department** dropdown
2. Select a department
3. Table shows only employees from that department
4. Click **Reset Filters** to show all employees again

### 💾 Backup Your Data
1. Click the **Export to CSV** button
2. A file downloads to your computer (usually to Downloads folder)
3. File name includes today's date
4. Open the CSV in Excel, Google Sheets, or any spreadsheet app

### 🌙 Enable Dark Mode
1. Click the **Dark Mode** button at the top right
2. Interface changes to dark theme
3. Your preference is saved automatically
4. Click again to return to light mode

## Tips & Tricks

### 💡 Pro Tips

1. **Consistent Department Names**
   - Use exact spelling: "Human Resources" not "HR"
   - Makes filtering more reliable

2. **Email Format**
   - Use company email format consistently
   - Makes search more effective

3. **Salary Entry**
   - Enter only numbers (50000 not $50,000)
   - System adds formatting automatically

4. **Regular Backups**
   - Export data monthly as backup
   - Save CSV files to cloud storage

5. **Browser Storage**
   - Data stays in your browser
   - Clear browser cache = data is deleted
   - Use export for permanent backup

6. **Quick Search Tips**
   - Search partial names (typing "John" finds "John Smith")
   - Search partial emails (typing "john@" finds all johns)
   - Search is case-insensitive

### ⚡ Keyboard Tips

1. Press **Tab** to move between form fields
2. Press **Enter** in form to submit
3. Click outside modal to close details window
4. Use **Ctrl+F** for browser-wide search

## FAQ

### Q: Where is my data stored?
**A:** Data is stored in your browser's local storage. It stays on your computer and is not uploaded to any server.

### Q: Will my data disappear?
**A:** Your data persists until you clear your browser cache. We recommend exporting regularly as backup.

### Q: Can I use this on my phone?
**A:** Yes! The application works on phones, tablets, and desktops. Buttons are large enough for touch.

### Q: How do I transfer data to another computer?
**A:** Export your data as CSV, then manually import by re-entering or copy-pasting into a spreadsheet.

### Q: Can multiple people use the same file?
**A:** Each person needs their own copy. Data is stored locally per browser.

### Q: Is my data secure?
**A:** Yes! No data leaves your computer. Everything stays local on your device.

### Q: What if I delete someone by mistake?
**A:** Unfortunately, deleted data cannot be recovered unless you have a CSV backup. Always export regularly.

### Q: Can I change department options?
**A:** The current version has predefined departments. You can edit the HTML file to add custom departments if technical.

### Q: Why can't I find the exported CSV file?
**A:** Check your Downloads folder. Most browsers save downloads there by default.

### Q: Can I use this offline?
**A:** Yes! The entire application works offline once opened in your browser.

### Q: How many employees can I add?
**A:** As many as your browser's storage allows (usually thousands). No practical limit for most uses.

### Q: Can I search by phone number?
**A:** Currently searching by name and email only. Phone search may be added in future versions.

### Q: What's the maximum salary I can enter?
**A:** Any number. The system handles large values automatically.

## Troubleshooting

### Data Not Saving?
1. Check if browser allows local storage
2. Try clearing browser cache
3. Try a different browser
4. Check if storage is full (unlikely)

### Search Not Working?
1. Make sure you're typing in the search box
2. Check spelling - search is exact match
3. Click "Reset Filters" and try again

### Dark Mode Not Working?
1. Try clicking the button twice
2. Check if your browser is in dark mode system-wide
3. Try a different browser

### Export Not Working?
1. Check if browser blocks downloads
2. Check popup blocker settings
3. Ensure you have at least one employee
4. Try a different browser

### Can't See Form?
1. Try scrolling up to the top
2. Refresh the page (Ctrl+R or Cmd+R)
3. Check browser zoom level
